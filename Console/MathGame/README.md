
# Math Game

## Project Plan

The game will include:

- **User interface:** Let users interact with the game.
- **Game engine:** Contain the game's logic.
- **Random value helper:** Generate random values for the math operations.
- **User data storage:** Save game-related user data in a database.

## User Data

Create a model to store each user's:

- Name
- Score
- Time
- List of operations played
- Score for each operation
